# How to enable Kanata

**Note: replace {username} in the file paths**

- Download the files and place them in the "C:\Users\{username}\Documents\Kanata" folder
- Edit the "Kanata" shortcut properties to add enabled ".kbd" files
- Copy the shortcut into the "C:\Users\{username}\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup" and "C:\Users\{username}\AppData\Roaming\Microsoft\Windows\Start Menu" folders
- Switch between configs using Kanata tray icon
